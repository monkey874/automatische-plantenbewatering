🌱 Slimme automatische plantenbewatering met Arduino en Home Assistant

📖 Over het project

Dit project is een slim automatisch bewateringssysteem dat gebruikmaakt van een Arduino UNO R4 WiFi, verschillende sensoren en Home Assistant.

Het doel van dit project is om planten automatisch water te geven wanneer de grond te droog wordt. De Arduino meet verschillende waarden en stuurt deze via wifi door naar Home Assistant. Vanuit Home Assistant kan de waterpomp handmatig of automatisch worden aangestuurd.
